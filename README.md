# Simple Free Website (Publish on GitHub Pages or Netlify)

This package contains a minimal single-page website you can publish for free.

## Files
- `index.html` — main page (Persian/Farsi content)
- `styles.css` — styling for the page
- `README.md` — this file

## Publish with GitHub Pages
1. Create a new repository on GitHub and upload the files.
2. Go to repo > Settings > Pages, choose the `main` branch and `/ (root)` folder, and save.
3. Wait a few minutes. Your site will be available at `https://USERNAME.github.io/REPO`.

## Publish with Netlify
1. Sign in to Netlify and choose "Add new site" > "Deploy manually".
2. Drag-and-drop the files onto Netlify.
3. Netlify will provide a free site URL; you can add a custom domain later.

## Notes
- To show ads (like Google AdSense), you must register and verify your site with the ad network and then paste their ad code into the ad placeholder.
- For instant donations, use PayPal.me or Buy Me a Coffee links.
- For Stripe payments you'll need serverless functions or a server to keep your secret keys secure.
